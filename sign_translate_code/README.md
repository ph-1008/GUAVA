# taiwan-hand-sign-language-translator

各級目錄基本上都有readme

# 目錄說明
## 文件
如目錄名，就是放各類文件的/實驗數據/表格/作圖的檔案
## Dataset
如目錄名，放了手語翻譯培訓教材的電子檔
## CODE
就是放所有實驗/GUI的，可看CODE的readme

# 本層文件說明
## output/2/3
手語語句對的文件，原始為output，2代/3代有做修正，看最新的3代就好

## chinese_value/2
手語辭彙的文件，看2代就好

## replace_data
手語辭彙有些是組合字，此檔案呈現如何組合

## 剩下
不重要，可略過

conda env create -f environment.yml
