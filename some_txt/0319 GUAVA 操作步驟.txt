1. -d (Device / GPU ID)
意思： 指定運算的裝置（Device）。
在此處的意義： -d ' 0 ' 通常表示使用編號為 0 的顯示卡（GPU）進行運算。如果是 -d -1，有時代表使用 CPU。
2. -m (Model Path)
意思： 指定模型（Model）的路徑。
在此處的意義： -m assets/GUAVA 表示程式要載入位於 assets/GUAVA 這個資料夾（或檔案）中的模型權重或設定檔。
3. -s (Save / Silent / Scale / Skip)
這個參數在沒有後續數值的情況下，通常是一個「開關」（Flag），具體意義取決於你使用的軟體，最常見的有幾種可能：
Save（儲存）： 執行完後自動儲存結果（例如圖片或影片）。
Silent（靜默模式）： 執行時不顯示詳細的日誌訊息（Log）。
Scale（縮放）： 如果是影像處理工具，有時代表特定的縮放倍率（但通常後面會接數字）。
Source（來源）： 指定輸入源（但通常後面會接路徑）。
